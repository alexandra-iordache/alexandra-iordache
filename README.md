### Featured work

- **[Scheduling Jobs with Security in Mind](https://github.com/alexandra-iordache/Dissertation-Project-Scheduling-Jobs-with-Security-in-Mind)** — final year dissertation. Three solvers (backtracking, fixed parameter tractable, and SAT) for the Workflow Satisfiability Problem, cross validated to 100% agreement across 120+ test instances, backed by 80+ unit tests, with a PySide6 desktop interface. `Python` `PySAT` `NetworkX`
- **[Personal Finance Intelligence Dashboard](https://github.com/alexandra-iordache/personal-finance-dashboard)** — full stack app that ingests bank CSV exports and categorises spending with rule based and machine learning tagging, plus forecasting and anomaly detection. `FastAPI` `React` `TypeScript` `scikit-learn`
- **[Student Records System](https://github.com/alexandra-iordache/CS2800)** — REST API built with Spring Boot, JPA and Spring Security, verified with a JUnit test suite. `Java`
